# InfraLens

InfraLens is an AI-powered infrastructure analysis and visualization platform.

## Vision

Help developers understand infrastructure by converting Infrastructure-as-Code into an interactive graph, running security and cost analysis, and generating AI-assisted explanations.

## Current Status

🚧 Under active development.

## Planned Stack

- FastAPI
- React + TypeScript
- PostgreSQL
- Redis
- Celery
- Go (Terraform/HCL parser)
- Docker
